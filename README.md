# GreatestTraderByClaude

トレード環境のための個人用ツール置き場。当面は **自分の資産・環境を不正アクセスから守る
防御的なセキュリティ強化**を目的としたスクリプトを中心に整備します。

## 設計方針（安全第一）

- まずは **検知・点検のみ（読み取り専用）** から。設定変更はしない。
- **新しい待受ポートを開けない**（監視は読むだけ・通知は外向き）。
- **秘密情報（パスワード/APIキー）はコードに直書きしない**（環境変数・資格情報ストアを使用）。
- 最小権限で動かす。
- 変更を伴うものは **1つずつ・元に戻せる形**で追加する。

## 構成

| フォルダ | 内容 |
|----------|------|
| [`pc-security/`](./pc-security) | 現在の Windows PC を守るためのツール（自己診断など） |
| [`aws/`](./aws) | AWS を片付ける際の読み取り専用インベントリ |

## ロードマップ（想定）

1. **現在のPCの保護**（最優先）
   - 自己診断（実装済み: `pc-security/Invoke-PcSecurityAudit.ps1`）
   - 診断結果に基づく強化手順
   - ログイン監視（検知のみ）
2. **AWS の片付け**（`aws/Inventory-AwsResources.ps1` で棚卸し → 手動削除）
3. 将来の **Windows VPS（Xserver / さくら 等）への移行**時に、初期セキュリティ設定を整備
