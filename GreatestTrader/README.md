# GreatestTrader v1.2.0（最終モデル）— FX 自動売買システム

**月利 5% を目標**とする、複数戦略の FX ポートフォリオです。

- v1.1：目標を保ったまま、**ドローダウンと月ごとの損失を抑える**リスク管理と、目的別の**プリセット**を追加しました。
- v1.2（最終モデル）：既定の **stable5** の売買ルールはそのままに、**何年も無人で動かし続けるための仕組み**を追加しました。

| | |
|---|---|
| 本稼働 | **Python**（MetaTrader 5 経由で発注） |
| テスト | **MQL5 EA**（MT5 ストラテジーテスター用。ライブ稼働にも利用可） |
| 戦略 | ① Night Reversion：日付変更直後の 14 通貨ペアで平均回帰を狙う ② Euro Session：欧州午前に EURUSD を売る |
| リスク管理 | 通貨ペア別のリスク配分、合計リスク上限、同一通貨・同一方向の上限、DD 連動の縮小、日次・月次の停止（月次は全決済）、年末年始の新規停止、最大 DD 停止 20% |
| 長期運用（v1.2） | 1 注文 20 ロットの上限、入出金の自動処理、サーバー時間の常時検証、MT5 の自動再接続、二重発注・二重起動の防止、状態ファイルの保護、日次サマリー・DD 警告・優位性モニターの通知、成績レポート |

## プリセットと過去検証の結果（2007/01〜2022/03、コスト込み）

「月利（複利換算）」は、資産が実際に増えたペース（(1+CAGR)^(1/12)−1）です。

| プリセット | 月利（口座が小さいうち）※1 | 最大 DD（含み損益込み） | 最悪月 | 1 万ドルから 15 年の月利（20 ロット上限込み）※2 | 向いている人 |
|---|---|---|---|---|---|
| **stable5（既定・推奨）** | **5.38%** | **−11.6%** | −4.75% | **3.07%** | 月利 5% を目指したい |
| stable4 | 4.37% | −10.7% | −3.67% | 2.93% | DD を抑えつつ急変動にも備えたい |
| safe2 | 2.00% | −11.7% | −2.00% | 2.00% | 毎月の損失を −2% 前後に抑えたい |
| classic_aggressive（v1.0 の設定） | 6.42% | −33.0% | −14.93% | 3.47% | 参考（保護機能なし） |

※1 1 注文のロット上限が効かない口座規模（約 6.6 万ドル＝約 1,000 万円まで）での成績。
※2 口座が大きくなると、1 注文 20 ロットの上限により利益は % ではなく金額でほぼ一定になります（詳細は [docs/06_長期運用評価報告書.md](docs/06_長期運用評価報告書.md)）。

> ⚠ **月利 5%・最大 DD 20% 以内・最悪月 −2% の 3 つを同時に満たすプリセットはありません**（[docs/05_安定化改修報告書.md](docs/05_安定化改修報告書.md)）。
> ⚠ 成績は取引コストに強く左右されます。コストが 0.5 pips 高いと stable5 の月利は 3.50% に下がります。10 年の模擬運用の中央値は 3.8〜5.1%（データの期間による）で、本番の現実的な期待値は月利 3% 前後です。
> ⚠ 優位性の劣化は見られませんが、2012〜2014 年のような数年単位の横ばい期があります（最高値の回復まで 1,176 日）。
> ⚠ 過去の検証結果は将来の利益を保証しません。必ずデモ口座で確認してから、リスクを半分にして始めてください。

## クイックスタート

### A. MT5 ストラテジーテスターで検証する（最初に推奨）

1. MT5 の [ファイル] → [データフォルダを開く] → `MQL5\Experts\` に `mql5/Experts/GreatestTrader.mq5` を、`MQL5\Presets\` に `mql5/Presets/*.set` をコピーします。
2. MetaEditor（F4）で `GreatestTrader.mq5` を開いてコンパイルします（F7）。
3. ストラテジーテスター（Ctrl+R）で次のとおり設定して [開始] を押します。
   - エキスパート：GreatestTrader
   - 銘柄：EURUSD
   - 時間足：M15
   - モデル：1 分足 OHLC（最終確認はリアルティック）
   - パラメータ：使うプリセットの .set を読み込む（例：`GreatestTrader_Stable5_Default.set`）

### B. Python で本稼働する（Windows）

1. MT5 を起動・ログインし、[アルゴリズム取引] を ON にします（**ヘッジング口座**が必要です）。
2. Python 3.13（64 ビット）をインストールし、`python\setup_windows.bat` を実行します。
3. `python\config\config.yaml` を編集します（シンボルの接尾辞、手数料、`preset:`、通知先）。
4. `1_check.bat` で接続を確認 → `2_run_dryrun.bat` でドライラン → デモ口座で `3_run_live.bat` を実行します。
5. 長期運用の設定（自動起動・通知・死活監視）と、毎日・毎月・年 1 回の確認手順は [docs/02_取扱説明書.md](docs/02_取扱説明書.md) の 7.4 節・9 章と [docs/06_長期運用評価報告書.md](docs/06_長期運用評価報告書.md) の 8 章を参照してください。

## 必要なレバレッジ（合計建玉の最大 ÷ 口座資産、口座が小さいうち）

| stable5 | stable4 | safe2 | classic_conservative / standard / aggressive |
|---|---|---|---|
| 約 67 倍 | 約 46 倍 | 約 18 倍 | 約 30 / 58 / 87 倍 |

国内口座（最大 25 倍）では safe2 を使ってください（口座が約 20 万ドルを超えて 20 ロット上限が効くようになると、stable5 でも 25 倍でほぼ足ります）。stable5 を小さな口座で使うには 100 倍以上の口座が必要です。

## 動作環境

- Windows 10 / 11 / Server、MetaTrader 5（ヘッジング口座）、Python 3.13（64 ビット）
- 推奨：ECN / RAW 口座（低スプレッド＋手数料型）、24 時間稼働の VPS
