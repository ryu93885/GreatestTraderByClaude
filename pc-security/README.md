# pc-security — 現在のPCを守るためのツール

このフォルダには、**使用中の Windows PC のセキュリティを点検・強化する**ためのスクリプトを置きます。
すべて「安全第一」の原則で作ります。

- 最初は **検知・点検のみ（読み取り専用）**。設定変更はしません。
- 新しい待受ポートを開けない設計。
- 秘密情報（パスワード/APIキー）はコードに直書きしない。
- 変更を伴うものは、後日あらためて「1つずつ・元に戻せる形」で追加します。

## Invoke-PcSecurityAudit.ps1 — セキュリティ自己診断（読み取り専用）

現在のPCのセキュリティ設定を点検し、所見レポートを1つの txt に出力します。
**設定は一切変更しません。**

### 実行方法

PowerShell を **管理者として実行**（右クリック →「管理者として実行」）してから:

```powershell
powershell -ExecutionPolicy Bypass -File .\Invoke-PcSecurityAudit.ps1
```

実行が終わると、最後に1行だけ結果（出力先と WARN/CHECK 件数）が表示されます。
レポートは既定でデスクトップに `pc_security_audit_YYYYMMDD_HHMMSS.txt` として保存されます。

### 点検項目

- OS / 最終更新（HotFix）
- Windows Defender（有効 / リアルタイム保護 / 定義の鮮度）
- ファイアウォール（各プロファイル）
- リモートデスクトップ(RDP)：有効状態 / NLA / 3389 の待受範囲
- 保存済み資格情報（cmdkey）と RDP 接続履歴
- ローカル管理者 / Guest / パスワード不要アカウント
- 自動ログオン
- UAC
- SMBv1
- BitLocker（システムドライブ）
- 全インターフェイスで待受している TCP ポート
- アカウントロックアウトのしきい値

### レポートの見方（凡例）

| 記号 | 意味 |
|------|------|
| `OK`    | 問題なし |
| `WARN`  | 要対応（設定の見直しを推奨） |
| `CHECK` | 要確認（権限不足などで判定できず） |
| `INFO`  | 参考情報 |

> ⚠️ レポートには**ユーザー名・ホスト名・接続履歴**が含まれます。共有する場合は中身を確認し、
> 必要に応じて該当箇所を伏せてください。

### 次のステップ（予定）

1. この診断結果（WARN 項目）をもとに、**具体的な強化手順**を用意
2. **ログイン監視ツール**（イベントID 4624/4625 を監視し、不審なログインを検知・通知）
   ※まずは「検知のみ」。自動ブロックは十分検証してから。
